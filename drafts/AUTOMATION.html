4. Default policy

  • Join: check roster and existing task, reuse authorised access, diagnose app/OS/runtime and start work if a supported runner exists.
  • Network/timeouts/rate limits: retry with backoff; then queue or use an already connected and authorised fallback.
  • Native permission prompt or expired login: do not fake clicks or bypass safeguards. Use a pre-authorised route; pause only the blocked job if none exists.
  • One consolidated notification only for expired authentication, a truly required permission, no available route, consequential-action approval or deadline risk.
  • External email sending, deletion, permission changes, spending, public release and legal filing remain approval-gated. Hive's existing email draft gate is unchanged.
