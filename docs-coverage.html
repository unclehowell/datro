Gaps
  • Read the Docs guide (ghf_legalwiki/guide_readthedocs) v1.1.0: HTML only; its PDF exists for v1.0.1 on Wayback. A PDF of the current version is a build task on Docs.
  • The test specimen (ghf_tests/specimen_loremipsum) has no PDF; it is not a catalogue entry.

How coverage is checked
  • Read docs.json; for each document and language, request the HTML path and the PDF link; both must answer 200.
  • Compare the EV ids in docs.json with the Evidence Register; every register id needs a document.
  • Run after every Docs build and record the numbers here.
