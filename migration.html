Artifacts

Every artifact (scan, PDF, image, audio, video) is stored once, on Wayback. Every other site links to it there and opens it in the shared artifact viewer. No site keeps its own copy.

The rule
  • Storage: the artifact file lives on wayback.bucklerfamily.estate, with a manifest entry. Its address never changes once published.
  • Use: other sites link to the Wayback address. With the viewer script loaded, a click opens the artifact in a popup over the page, with Open and Download buttons.
  • Not artifacts: a site's own interface files (icons, fonts, theme images, its own generated diagrams) stay with the site.
  • Never delete the only copy. A duplicate is removed only after the Wayback copy is verified live (200, same bytes) and every reference to the old copy is repointed and checked.
The artifact viewer (shared script)

Add one line before </body> on any page:

<script src="https://wayback.bucklerfamily.estate/viewer/ghf-viewer.js" defer></script>
  • Links to wayback.bucklerfamily.estate open in the viewer; any other link opens in it when it carries data-ghf-view. data-ghf-noview or a download attribute keeps normal behaviour, as do Ctrl/Cmd/Shift/middle clicks.
  • Images, audio and video use the browser's own players; PDFs and pages open in a frame. Escape or the ✕ closes it.
  • Styles are isolated in a shadow root, so the host page's design is untouched (the design freeze holds).
  • Programmatic use: ghfViewer.open(url, label).
  • Cross-origin check (24 Oct 2026): Wayback answers PDFs and JSON with Access-Control-Allow-Origin: * and sends no frame-blocking header, so frames and fetches from other sites work.
  • Test page: wayback.bucklerfamily.estate/viewer/.
Duplicate inventory (24 Oct 2026)

Method: every file on every branch of the datro repository compared by its git blob hash (identical hash means identical bytes). 47 branches carry artifact files: 50,768 files, 7,563 distinct. 5,553 distinct artifacts appear on two or more branches, almost all on archive and backup branches that serve no site.

On the 16 branches that serve live sites: 2,011 distinct artifacts; 29 are duplicated across live branches (theme files excluded), 3 of them already have a Wayback copy.

  • bpvsbuckler, qa and 2026-10-22 share a common base: 19 media files under static/bpvsbuckler/media, 4 images and 2 PDFs under a wayback/ folder, and 3 evidence-catalogue PDFs whose identical copies are on Wayback (pdf/foi/2026-10-05_museum-wales_foi-2026-036_*).
  • Single copies held on a site branch but not on Wayback: the Farm Album (318), the e-book shelf (96), the Map Room (73), the gift shop (33), the land-transfer graphic (24) and smaller sets. Each needs sorting into artifact (move to Wayback) or interface file (stays).
  • The full list with hashes and paths: duplicates-live.csv; counts: duplicates-summary.json.
Migration procedure (per site)
  1. List the site's artifact files and match each to Wayback by hash.
  2. For a file with no Wayback copy: add it to Wayback with a manifest entry (class B change on Wayback); wait for it to serve 200 with the same bytes.
  3. Repoint every reference on the site to the Wayback address; load the viewer script.
  4. Verify live: every repointed link opens in the viewer at 390 px and 1280 px.
  5. Only then remove the site's copy, in its own commit naming the Wayback address that replaces it.
  6. Log the site as migrated below.
