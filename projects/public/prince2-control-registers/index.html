R-015 — Preserve Gmail draft artifacts before any deletion

Cause: a HubSpot task (529330607290) calls for deletion of 57 Gmail drafts labelled DON’T SEND, while the connected Gmail tool is unavailable in this session and the individual drafts have not been inventoried here. Event: a source draft, recipient list, message ID, embedded research or provenance disappears before it has been preserved. Effect: permanent loss of an artifact or audit context.

Control: hold the deletion action. Do not delete drafts solely to clean up counts. First export or capture each draft’s full body, recipients, subject, message ID, last-modified metadata and reason for hold; reconcile it to the HubSpot task and any source artifact; record a preservation location/checksum where available. Only then may Sion review deletion of individually classified superseded drafts.
