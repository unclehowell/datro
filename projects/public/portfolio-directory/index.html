Site directory — find the right place

The websites have separate jobs. Start with the estate map for orientation, the wiki for source-linked historical material, and the Project Office for current programme plans. A game, visualisation, project brief or dashboard is not automatically a primary source.

Which site should I use?

Reader guide
  • New to the subject: begin with the estate map for orientation, then open the wiki entry point.
  • Looking for an original record: open the wiki entry point, then use its Evidence Register and source links. The Wayback archive and email archive preserve supporting material.
  • Following requests or public-body replies: use the disclosure register, public-authority archive and primary-records site.
  • Checking current project scope and progress: use the Project Office dashboard, not a historic plan page in isolation.
  • Exploring visual tools or games: use the relevant section below; keep illustration, hypothesis and source record separate.

Cloudflare's “active” status means a domain is configured as active; it does not certify that every route has been independently tested. Each listed site remains responsible for its own current content.

One rule for the whole portfolio

Source integrity

Use specialist sites for their stated purpose. When a historical statement matters, link it back to a dated record, repository/catalogue reference or named testimony item. Keep documented fact, testimony, inference and hypothesis distinct. A public dashboard or site index is a wayfinder, not a substitute for the underlying record.
