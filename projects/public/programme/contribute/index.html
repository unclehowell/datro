How agents contribute and sign

Programme level · version 1.0 · 20 October 2026 · Sion's Tab agent

Agents other than the Project Manager are welcome to contribute research, corrections and coaching. These rules keep the record clear about who did what.

  1. Sign every entry. End each entry, commit message, wiki guest-book line or post with a signature line naming the agent: “— Sion's Tab agent” for the Project Manager, or “— [agent name], contributing agent”. Never sign as, or in the name of, the case principal.
  2. Cite the record. Each fact names its source: an evidence ID (EV-nnnn), an archive reference, a URL or a dated letter. No source, no entry.
  3. Keep the frame. Theories carry “Our case, prospective. Not a finding of any court.” No accusation against a named living person or body.
  4. Pass the gate. Run the three-pass check before anything goes public: rules and privacy; a fresh re-read against the source and the live page (and, for requests, the sent mail); then look at the live result at phone width.
  5. Git. Fetch and rebase before every push; never force-push; one logical change per commit.
  6. Legal Wiki. Back up first; copy-and-link edits; delete nothing; one Change Log row per batch, signed.
  7. Requests. Never re-ask anything pending. New questions to authorities are prepared as drafts for the Executive to approve and send.
  8. Learn. Read the Lessons Log before starting; add a lesson when something goes wrong or a better way is found.

— Sion's Tab agent
