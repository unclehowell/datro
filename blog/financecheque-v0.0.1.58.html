Release financecheque-v0.0.1.58

2026-08-12 · Release #158 for financecheque

This release brings the child proxy install script, documentation, and WebGUI docs into alignment with the actual local machine architecture.

  • fix(install.sh): install.sh now installs the full child proxy stack — agentos-gui WebGUI (localhost:3000), child-proxy.mjs (port 4001), llama-server + MiniCPM-1B (port 8090), kiro-cli, kilo, hermes, Whisper STT, Piper TTS, pm2
  • fix(install.sh): all services managed by pm2 with autostart on boot
  • fix(static/financecheque/fcukproxy/install.sh): was a stub; now a proper redirect to public/install.sh
  • docs(docs.html): completely rewritten to accurately document parent proxy API, child proxy API, WebGUI API, local agent tools (kiro, kilo, hermes), voice pipeline (Whisper STT + Piper TTS), routing policy, OTA, and troubleshooting
  • docs(agentos/gui/src/app/docs/page.tsx): WebGUI docs page rewritten to reflect actual local stack — MiniCPM-1B local LLM, child-proxy routing, kiro/kilo/hermes CLI tools, voice pipeline, parent proxy API, all local endpoints
  • docs(agentos/gui/docs/CHILD_PROXY_ARCHITECTURE.md): rewritten with accurate service table, pipelines, routing policy, and install command
  • chore: bump version to 0.5.1.93
  • note: OpenClaw is explicitly out of scope for the FinanceCheque child proxy stack

    • These changes ensure that running the one-liner installer from financecheque.uk/fcukproxy/install.sh results in the same running stack as the reference child proxy (WebGUI at localhost:3000/chat, local LLM, agent CLI tools).

    For full details, see the GitHub release.
