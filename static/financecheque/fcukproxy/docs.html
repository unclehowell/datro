FCUK Proxy Documentation

Version: 0.5.0

Quick Start

Install a child proxy on any device (laptop, phone, server):

curl -fsSL https://www.financecheque.uk/fcukproxy/install.sh | bash

This makes your device a child proxy on the FinanceCheque network.

Architecture Overview

Parent Proxy

Hosted on financecheque.uk

  • Routes queries to child proxies
  • LLM API responses via environment keys
  • Never routes back to source machine

Child Proxy

Runs on your devices (port 4001)

  • Listens for OpenAI-compatible requests
  • Forwards to parent proxy by default
  • Loop prevention via X-Forwarded header

Routing Policy

Boolean Logic

C = Chat-only | F = X-Forwarded | A = Agentic prompt

Parent Proxy Decision Tree

IF X-Forwarded == true:
  → Use LOCAL LLM ONLY (loop prevention)
  → NEVER route to child proxies
ELSE IF X-Agentic == true:
  → Route to designated agentic child (e.g., phone)
ELSE IF X-Chat-Only == true:
  → Respond via LLM APIs (env keys on Cloudflare)
ELSE:
  → Route to available child proxy
  → NEVER route back to requesting child

Child Proxy Decision Tree

IF X-Forwarded == true:
  → Use LOCAL LLM ONLY
  → This request came FROM parent (loop prevention)
ELSE:
  → Forward to parent proxy
  → On timeout/retry exhaustion: local LLM fallback
  → NEVER query parent API for responses

Headers

HeaderMeaningUsage
X-Chat-Only: trueChat query (no agentic)Child → Parent
X-Forwarded: truePrevent loop (came from parent)Parent → Child
X-Agentic: trueAgentic prompt (needs agent)Child → Parent
X-Source-MachineTell parent who sent requestChild → Parent

Hermes Agent Integration

When using Hermes agent on a child proxy device:

  • Chat queries route through parent proxy → LLM APIs
  • Agentic prompts route to designated agentic child (e.g., phone)
  • Fallback to localhost only after retry exhaustion
  • Telegram pairing uses same routing logic

Set role via environment: AGENT_ROLE=agent curl -fsSL https://www.financecheque.uk/fcukproxy/install.sh | bash

# Parent Proxy (Cloudflare Worker secrets)

ANTHROPIC_API_KEY=sk-ant-...

CHILD_ID=auto-generated
PORT=4001
AGENT_ROLE=chat|agent
