FCUK Proxy API Documentation

Install

Make any device a child proxy:

curl -fsSL https://www.financecheque.uk/fcukproxy/install.sh | bash

Agentic node (for compute offload):

AGENT_ROLE=agent curl -fsSL https://www.financecheque.uk/fcukproxy/install.sh | bash

Headers

HeaderValuePurpose
X-Chat-OnlytrueChat query (no agentic)
X-ForwardedtrueLoop prevention (came from parent)
X-AgentictrueAgentic prompt for agent processing
X-Source-Machinemachine-idIdentifies requesting child

Routing Logic

Parent Proxy Decision Tree:
  IF X-Forwarded == true:
    → Use LOCAL LLM ONLY (prevent loop)
  ELSE IF X-Agentic == true:
    → Route to agentic child (e.g., phone)
  ELSE IF X-Chat-Only == true:
    → Respond via LLM APIs (env keys on Cloudflare)
  ELSE:
    → Route to available child (not source)

Child Proxy Decision Tree:
  IF X-Forwarded == true:
    → Use LOCAL LLM ONLY (prevent loop)
  ELSE:
    → Forward to parent proxy
    → Fallback to local LLM after 3 retries/timeouts
