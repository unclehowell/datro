# MEMORY.right.md

## Steering Block
steering block #E17055 at right

Branch: **pirateclaw**
Color: #E17055
Position: right
Joystick Direction: RIGHT/E

When the COMMAND cockpit joystick is positioned toward **RIGHT/E**,
this block appears as a small #E17055 bar on the **right** side
of the pirateclaw.datro.directory website.

### Light/Dark Variants
- **Light** (joystick magnitude < 0.6): opacity 35%
- **Dark** (joystick magnitude >= 0.6): opacity 90%

### Center Position
When the joystick is centered (CTR), all steering blocks are removed
from this branch's website during the next flywheel rerelease cycle.
