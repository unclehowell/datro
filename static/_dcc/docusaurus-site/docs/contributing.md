# Contributing

Thank you for considering contributing to the Debt Cancellation Circle (DCC) project! We welcome contributions that help improve the application, documentation, or user experience.

## How to Contribute

### 1. Reporting Bugs

If you find a bug, please check if it has already been reported. If not, open a new issue on the project's issue tracker. Provide as much detail as possible, including:

*   A clear, descriptive title.
*   Steps to reproduce the bug.
*   The expected behavior vs. the actual behavior.
*   Screenshots or error messages (if applicable).
*   The environment you are using (browser, OS).

### 2. Suggesting Enhancements

We are always looking for ideas to improve DCC. Feel free to open an issue to suggest new features or improvements.

### 3. Contributing Code

For code contributions (e.g., bug fixes, new features):

1.  **Fork the repository.**
2.  **Create a new branch** for your feature or bugfix.
3.  **Make your changes** and ensure they are well-tested and follow the project's coding style.
4.  **Add or update documentation** as necessary.
5.  **Commit your changes** with clear and concise commit messages.
6.  **Submit a Pull Request (PR)** against the main branch.

## Development Setup

Refer to the [Getting Started](./getting-started.md) guide for instructions on setting up the development environment.

## Code Style and Conventions

*   The project uses a minimalist, 90s-inspired aesthetic. Code should be clean and straightforward.
*   Follow standard HTML, CSS, and JavaScript best practices.
*   When contributing to existing JavaScript logic, try to match the existing style.
