# RULES — cnei Discovery

## Discovery Rules
1. Prioritise sources that can be freely accessed and verified
2. For paywalled sources, record the reference for potential future access
3. Cast a wide net initially, then narrow focus on most promising leads
4. Cross-reference findings across multiple sources for triangulation
5. Record dead ends and unproductive searches to avoid repeating them
6. When a new source type is discovered, document how to access it
