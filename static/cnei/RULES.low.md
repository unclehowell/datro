# RULES — cnei Quality Control

## Quality Rules
1. Every treeview entry must have a filled tags array for discoverability
2. Text entries must include source attribution in the first line
3. Image entries must include a caption/description in treeview tags
4. PDF entries must include page count where known
5. Video entries must include duration where known

## Process Rules
1. Each cycle, start by reviewing MEMORY.md for ongoing leads
2. Record search queries and results in MEMORY.md
3. Flag potential leads that require human intervention
4. Report new findings to honcho memory and monday.com
