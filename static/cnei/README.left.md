# cnei — The Meta-Branch (Left Wing)

## What We're Building
cnei is the self-improving control plane for the entire datro repository. It hosts the **Cloudflare Flywheel Worker** — a 3-tier AI/best-practice/audit engine that scans every branch, proposes improvements, and auto-patches code. It also runs the **dashboard** (localhost:3000), a real-time GUI for steering the flywheel via bias/risk controls, editing wing files, and visualizing the branch tree.

## Vision
A fully autonomous code ecosystem where the flywheel continuously improves every branch — fixing bugs, adding features, and refining documentation — while humans steer via the dashboard's 2D pad. Wing files are the "personality" of each branch, telling the AI how aggressive, conservative, risky, or safe to be. cnei is the brain that reads those wings and flies.

## Roadmap
1. **Phase 1 (done):** Flywheel worker deployed, dashboard operational, 16 wing files per branch
2. **Phase 2 (now):** Auto-seeding wing files on branch creation, cross-branch diffing, parallel brain aggregation
3. **Phase 3 (next):** Self-tuning flywheel thresholds, multi-repo support, dashboard push-to-deploy
4. **Phase 4 (future):** Full autonomous mode — AI proposes, tests, deploys, and monitors itself
