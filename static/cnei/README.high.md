# cnei — Evidence Discovery Engine for Great House Farm

## Purpose
cnei is the evidence discovery and curation flywheel for the Datro project. Its sole mission is to seek, verify, and archive original evidence and citations about Great House Farm, Llandough (nr. Penarth, Vale of Glamorgan).

## How It Works
1. Each flywheel cycle, the AI agent loads these wing files to understand its mission
2. It searches archives, databases, and other sources for relevant evidence
3. When found, it adds the evidence to the wayback library with a standardised filename
4. It logs discoveries and search attempts in MEMORY.md
5. Results are synced to honcho memory and monday.com for tracking

## Geographic Clarification
- **Great House Farm (aka Ty Mawr)** is in Llandough, nr. Penarth, Vale of Glamorgan
- This is **NOT** Llandough near Cowbridge / Y Bont-faen
- This is **NOT** Landow / Llandow (another village in the Vale)
