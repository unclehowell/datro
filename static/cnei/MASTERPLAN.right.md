# MASTERPLAN (right) — cnei

## Phase 1: Discovery Sprint
- Cast wide net across all sources simultaneously
- Prioritise discovering NEW evidence not already in wayback
- Aim for volume of leads rather than completeness per source

## Phase 2: Verification
- Follow up on promising leads with detailed research
- Request copies of paywalled or offline records
- Cross-reference newly discovered items with existing collection

## Phase 3: Integration
- Add all verified evidence to wayback with standardised names
- Update treeview JSON with complete metadata
- Tag evidence for cross-referencing (people, places, dates, topics)
