# Consortium Projects Document

This document contains the official documentation for DATRO Consortium projects,
with a focus on email marketing configuration and infrastructure.

## Building the Document

Run the rebuild script to generate HTML and PDF output:

```bash
cd /home/ubuntu/datro/static/library/consortium_projects
./rebuild.sh
```

## Output

- HTML output: `latest/build/html/`
- PDF output: `latest/build/latex/`

## Access

The document is accessible via: `library.datro.xyz/consortium_projects/`
