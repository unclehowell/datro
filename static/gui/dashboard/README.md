# GUI Dashboard README

The GUI dashboard is a centralized hub for accessing various applications and tools. It is divided into categories, each representing a specific group of related apps.

## User Experience

1. **Category Selection**: The user navigates to a category page, such as A.I Agents or Entertainment.
2. **App Store Access**: On the category page, a '+' app icon is visible. Selecting this icon takes the user to the app store page corresponding to the category.
3. **App Selection**: In the app store, the user can toggle the apps they want to appear on the dashboard page.
4. **Dashboard Update**: After toggling, the user returns to the category page, where the selected app icons are now visible.
5. **App Launch**: Selecting an app icon on the dashboard page opens the corresponding application.

## Standardization

The following features are standardized across most dashboard and app store pages:

* Category pages have a '+' app icon that links to the corresponding app store page.
* App store pages allow users to toggle apps, which updates the dashboard page accordingly.
* Dashboard pages display app icons, which launch the corresponding applications when selected.

## Customization

The A.I Agents category page has been customized to include specific app icons and layouts. This customization may not be consistent with other categories.
