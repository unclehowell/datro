# SCHEMA.left.md

## Steering Block
steering block #AA96DA at left

Branch: **dcc**
Color: #AA96DA
Position: left
Joystick Direction: LEFT/W

When the COMMAND cockpit joystick is positioned toward **LEFT/W**,
this block appears as a small #AA96DA bar on the **left** side
of the dcc.datro.directory website.

### Light/Dark Variants
- **Light** (joystick magnitude < 0.6): opacity 35%
- **Dark** (joystick magnitude >= 0.6): opacity 90%

### Center Position
When the joystick is centered (CTR), all steering blocks are removed
from this branch's website during the next flywheel rerelease cycle.
