Source coverage and exclusions

The registry contains hostnames discovered in Cloudflare plus the original WordPress wiki. The indexer is designed for current Git branch heads and published public HTML/text. Private API services and PDF document bodies are not included by default. Pages that fail or exceed crawl limits are reported rather than silently counted as complete.

    Pull request result

    Every contribution is a proposal. Tumbler verifies all indexed branch heads before creating a draft pull request. A human must review it. The app never merges, deploys, or writes to a source branch. Private APIs, PDF bodies, binaries and files excluded by the published indexing limits are not silently described as assessed.

    Select a methodology and review filters, then assess the whole collection. If a substantive improvement is justified, Tumbler will open a draft pull request and link it here.
