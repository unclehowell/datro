# RULES.low.md

## Steering Block
steering block #FF6B6B at bottom

Branch: **althea**
Color: #FF6B6B
Position: bottom
Joystick Direction: LOW/S

When the COMMAND cockpit joystick is positioned toward **LOW/S**,
this block appears as a small #FF6B6B bar on the **bottom** side
of the althea.datro.directory website.

### Light/Dark Variants
- **Light** (joystick magnitude < 0.6): opacity 35%
- **Dark** (joystick magnitude >= 0.6): opacity 90%

### Center Position
When the joystick is centered (CTR), all steering blocks are removed
from this branch's website during the next flywheel rerelease cycle.
