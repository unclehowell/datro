# CONTEXT.high.md

## Steering Block
steering block #FF2E63 at top

Branch: **llmwiki**
Color: #FF2E63
Position: top
Joystick Direction: HIGH/N

When the COMMAND cockpit joystick is positioned toward **HIGH/N**,
this block appears as a small #FF2E63 bar on the **top** side
of the llmwiki.datro.directory website.

### Light/Dark Variants
- **Light** (joystick magnitude < 0.6): opacity 35%
- **Dark** (joystick magnitude >= 0.6): opacity 90%

### Center Position
When the joystick is centered (CTR), all steering blocks are removed
from this branch's website during the next flywheel rerelease cycle.
