# 🏎️ PCP Refund: Reclaiming Consumer Justice

> **Were you mis-sold car finance?** Join thousands of UK consumers reclaiming what they’re owed. The FCA is investigating secret commissions—you could be entitled to thousands.

---

## ⚡ The Mission
Personal Contract Purchase (PCP) is the most common way to finance a car in the UK. However, for years, lenders and dealers used **"discretionary commission arrangements"** to inflate interest rates without telling customers. 

The more interest you paid, the more commission the dealer earned. This hidden conflict of interest is now under the spotlight, and we're here to help you get your money back.

### 💰 Why It Matters
- **£1,100** – Average estimated refund value per claim.
- **Justice for All** – Holding multi-billion pound lenders accountable for unfair practices.
- **Legal Precedent** – Setting a standard that protects future car buyers from hidden fees.
- **Community Power** – A collective movement of thousands seeking what they are owed.

## 🛠️ Built With
This project is a modern, high-performance web application designed for clarity, speed, and ease of use.

- **Frontend:** React + TypeScript
- **Styling:** Tailwind CSS + Framer Motion for smooth animations
- **Icons:** Lucide React
- **Content Management:** Integrated with [Puck](https://measured.co/puck) for visual editing capabilities.
- **Deployment:** Optimized for Cloudflare Pages (includes `functions/` for serverless API logic).

## 🚀 Getting Started

### Prerequisites
- Node.js (Latest LTS recommended)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/unclehowell/pcp2.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Project Structure
- `src/pages`: Core application views (Home, Claim, News, About).
- `src/components`: Reusable UI components like the `ClaimForm`.
- `functions/`: Cloudflare Pages Functions for handling API requests (e.g., claim submissions).
- `puck.config.tsx`: Configuration for the visual editor.
