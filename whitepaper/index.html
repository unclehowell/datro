The Concept

🐍

The classical Ouroboros — a snake eating its own tail — represents a closed loop that shrinks. We invert it: a system that starts minimal and expands with every addition, like a snake regurgitating its tail outward.

A single install command gives you a working AI assistant. Each subsequent step — adding OAuth, adding Kiro, adding Hermes, adding Telegram — doesn't just add a feature. It adds a capability multiplier that makes every previous component more powerful.

This is an Algocracy: a system governed by an algorithm that understands its own history, corrects its own mistakes, and grows more valuable the more it is used.

Cloudflare Worker

The parent proxy at kiro.financecheque.uk holds API keys as Cloudflare Secrets (never in code). It round-robins across registered sub-proxies and falls back to direct API calls when no machines are available. Any machine can register itself via POST /api/register.

Sub-proxy

Each machine runs a Python sub-proxy on ports 5000 and 4117. It loads API keys from ~/kiro-proxy.env, routes model=kiro to a live kiro-cli tmux session, and falls back through the provider chain. Installed as a systemd user service — survives reboots.

The Memory System

Memory is stored in two complementary systems:

  • Honcho — structured peer/session/message memory with reasoning conclusions
  • Mem0 — semantic memory with automatic deduplication

An hourly cron job runs the Boolean Simplifier pipeline:

  1. Pull all memories from every Honcho org and Mem0 account
  2. Send each to the LLM with a Boolean algebra simplification prompt
  3. Contradictions are deleted. Redundancies are collapsed. Complex logic is simplified.
  4. Push the simplified pool back to all accounts

The result is a Mind Palace — a semantic knowledge base that gets cleaner and more precise over time, not noisier. Every conclusion has a traceable paper trail from inception to present. When a mistake is corrected, the system can identify exactly when the disorganised thinking occurred and why, and put measures in place to prevent recurrence.

This self-reflective audit trail is what makes the Algocracy valuable: not just intelligence, but accountable intelligence.

The Community System

Each machine that installs the proxy joins a federated pool. The Cloudflare worker round-robins across all registered machines. If the parent goes down, Hermes falls back to the local sub-proxy directly. If the local sub-proxy is busy, it can route to a neighbour's machine.

Bot-to-Bot Telegram Network

Each Hermes agent has a Telegram bot. All bots join a shared channel in bot2bot mode — they can consult each other for answers, delegate tasks, and share load. A user's WhatsApp interface mediates through their Telegram bot, which in turn can query the entire network.

When a user asks a question, their WhatsApp Hermes profile consults the Telegram profile, which queries the bot network for the fastest or most knowledgeable response. While idle, each agent serves others in the community — contributing to the hive mind rather than sitting dormant.

LLMWiki — The Shared Mind Palace

The Boolean-simplified memories are published to llmwiki.financecheque.uk — a living knowledge base that every Hermes agent consults on startup. It is the distilled, simplified, contradiction-free output of the entire community's collective reasoning. The more agents contribute, the more valuable it becomes.

Install

curl -fsSL https://kiro.financecheque.uk/install.sh | sh

This single command installs the sub-proxy, starts kiro in tmux, configures Hermes, registers with the Cloudflare worker, and sets up auto-update. Everything else is added progressively via the Web GUI at localhost:8080.
