Entries (verbatim)
------------------

- Slater’s 1868, p.902, Llandough: “Rees Thomas, Llandough Penarth … Williams John, Great house” (`directory page <https://leicester.contentdm.oclc.org/digital/collection/p16445coll4/id/91309>`__)
- Worrall’s 1875, p.324: “IN LLANDOUGH PARISH. David Job, Merry Harrier / Rees Thomas, Llandough / Williams John, Great house” (`directory page <https://leicester.contentdm.oclc.org/digital/collection/p16445coll4/id/348840>`__)
- Slater’s 1880, p.533: “IN LLANDOUGH. David Job, Merry Harrier / Rees Thomas, Llandough / Williams John, Greathouse” (`directory page <https://leicester.contentdm.oclc.org/digital/collection/p16445coll4/id/90316>`__)
- Owen’s Cardiff Directory 1887, p.209: “Williams John, Great House farm, Llandough” (`directory page <https://leicester.contentdm.oclc.org/digital/collection/p16445coll4/id/92950>`__)
- Owen’s 1891, p.237: “Williams John, overseer, Great House farm, Llandough” (`directory page <https://leicester.contentdm.oclc.org/digital/collection/p16445coll4/id/93394>`__)
- Cardiff Directory 1901, p.309: “Williams John, Great House farm, Llandough” (`directory page <https://leicester.contentdm.oclc.org/digital/collection/p16445coll4/id/95085>`__)

Name trap: Slater’s 1880, p.390, “Thomas David, Great House” is Llandough near Cowbridge, not this parish (`directory page <https://leicester.contentdm.oclc.org/digital/collection/p16445coll4/id/90173>`__).

**Proves:** Published directories list a John Williams at “Great house” / “Great House farm”, Llandough, in 1868, 1875, 1880, 1887, 1891 and 1901, and list Thomas Rees separately at “Llandough” in 1868, 1875 and 1880.

**Does not prove:** Tenure, acreage, title or rights. Directory entries are names supplied to the publisher. That the 1881 census “Llandough Home Farm” household is the same holding is supported by these entries but is an inference (see EV-0224).
