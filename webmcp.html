Machine access

WebMCP lets an AI agent working inside a browser call a site's tools directly. Status: implemented on every bucklerfamily.estate site through the shared agent layer.

How it works
  • Each site's home page (and every page that loads the shared header) loads /agent/webmcp.js when the browser offers navigator.modelContext.
  • The script registers the site's read-only tools with registerTool (or provideContext on older builds). Each tool is the same call as GET /agent/tool/<name>.
  • Without WebMCP, the same tools answer as plain GET requests (see the API reference).
  • All tools are read only. No tool writes, sends or pays.

Calling a tool from an agent
// in a browser with WebMCP
const tools = await navigator.modelContext.listTools?.();
// or without WebMCP
const r = await fetch("https://qa.bucklerfamily.estate/agent/tool/search_qa_kb?q=1974");
const data = await r.json();
Adding a tool (change control)
  • A new tool is a class B change on the shared agent layer: name, description, input schema, the data file it reads, and a test call.
  • Tools read published data files only; they never compute new facts.
  • After deploy, check /.well-known/mcp.json lists the tool and a GET call returns data.
