# Master Plan: wayback.datro.xyz

## Vision
Establish wayback.datro.xyz as a well-organized, searchable file archive for the DATRO Consortium's historical documents and media. Within 12 months, it should provide easy browsing by file type (TXT, PDF, Video, Image) with full-text search and metadata.

## Category
Archive

## Current Status
Live JS-generated file tree archive (v0.0.1.02) organized by file type categories: TXTs, PDFs, Videos, Images. Google Analytics present without cookie consent. Has DATRO logo. Missing privacy policy, cookie consent banner, social links, contact form, blog, and search functionality.

### Phase 1 — Compliance & Foundation

- [ ] Add Terms of Service page
- [ ] Fix DNS / Cloudflare connectivity if offline
