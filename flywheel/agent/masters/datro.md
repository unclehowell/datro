# Master Plan: datro.xyz

## Vision
Establish datro.xyz as the definitive consortium hub and flagship portal for all DATRO ecosystem projects. Within 12 months, it should serve as a performant, accessible gateway that clearly communicates the consortium's mission, members, and initiatives.

## Category
Meta

## Current Status
Live React SPA shell with comprehensive sitemap covering 39+ legacy pages. Google Analytics present without cookie consent. Robots.txt exists but visible content is JS-rendered with no meaningful static fallback. Privacy, cookies, social, blog, and contact sections are missing or empty.

## Strategic Roadmap

### Phase 1 — Compliance & Foundation
- [ ] Add Privacy Policy page
- [ ] Add Cookie Consent banner (GDPR compliant)
- [ ] Add Terms of Service page
- [ ] Fix DNS / Cloudflare connectivity if offline

### Phase 2 — Content & Identity
- [ ] Ensure title and brand match the subdomain name
- [ ] Write meta description and OG tags
- [ ] Add contact information
- [ ] Create dedicated email: datro@datro.xyz
- [ ] Create social media accounts relevant to the site's purpose

### Phase 3 — Engagement & Growth
- [ ] Launch blog at /blog/ with subject-matter posts
- [ ] Add social media links and share buttons
- [ ] Implement newsletter or notification system
- [ ] Add sitemap.xml and robots.txt

### Phase 4 — Excellence
- [ ] Core Web Vitals green
- [ ] Add JSON-LD structured data
- [ ] Full accessibility (WCAG 2.1 AA)
- [ ] Search functionality
- [ ] Analytics with privacy-compliant tracking

## Required Features
- Email: datro@datro.xyz
- Social: platform-specific accounts
- Blog: /blog/ with RSS feed, one post per flywheel release
- Compliance: Privacy, Cookie, Terms pages
- Contact: form or email link

## Success Criteria
- Server-side rendering or pre-rendered static content visible without JavaScript
- Cookie consent banner implemented alongside privacy-compliant analytics
- All 39+ legacy sitemap routes verified and functional
- Consortium branding, mission statement, and member directory published on homepage
