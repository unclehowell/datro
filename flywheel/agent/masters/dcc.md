# Master Plan: dcc.datro.xyz

## Vision
Transform dcc.datro.xyz into a vibrant community portal for the DATRO Consortium's cryptocurrency and blockchain initiatives. Within 12 months, it should offer rich educational resources, community tools, and transparent project tracking alongside its retro aesthetic.

## Category
Community

## Current Status
Minimalist retro terminal-style page with green-on-black theme. Links to wallet/ledger and Docusaurus documentation. Very sparse — no privacy policy, cookie consent, social media, contact form, blog, branding beyond the terminal style, or SEO metadata.

## Strategic Roadmap

### Phase 1 — Compliance & Foundation
- [ ] Add Privacy Policy page
- [ ] Add Cookie Consent banner (GDPR compliant)
- [ ] Add Terms of Service page
- [ ] Fix DNS / Cloudflare connectivity if offline

### Phase 2 — Content & Identity
- [ ] Ensure title and brand match the subdomain name
- [ ] Write meta description and OG tags
- [ ] Add contact information
- [ ] Create dedicated email: dcc@datro.xyz
- [ ] Create social media accounts relevant to the site's purpose

### Phase 3 — Engagement & Growth
- [ ] Launch blog at /blog/ with subject-matter posts
- [ ] Add social media links and share buttons
- [ ] Implement newsletter or notification system
- [ ] Add sitemap.xml and robots.txt

### Phase 4 — Excellence
- [ ] Core Web Vitals green
- [ ] Add JSON-LD structured data
- [ ] Full accessibility (WCAG 2.1 AA)
- [ ] Search functionality
- [ ] Analytics with privacy-compliant tracking

## Required Features
- Email: dcc@datro.xyz
- Social: platform-specific accounts (e.g., Telegram, Discord, or blockchain forums)
- Blog: /blog/ with RSS feed, one post per flywheel release
- Compliance: Privacy, Cookie, Terms pages
- Contact: form or email link

## Success Criteria
- Retro terminal theme preserved with added content pages
- Privacy, cookie, and terms pages live
- At least one social community channel linked (Telegram, Discord, or similar)
- Blockchain/crypto project roadmap or status dashboard published
