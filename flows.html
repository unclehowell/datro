Repo housekeeping · Information flows

Where each fact lives, who reads it, and which way it moves. One rule above all: Wayback is the single artifact store. Every scan, PDF, photograph, recording and email copy is kept once, on Wayback, and every other site links to it and opens it in the shared viewer.

The flow in one picture

  Archives and public bodies (NLW, Glamorgan Archives, HMLR, courts, councils)
        │  originals, catalogue references
        ▼
  WAYBACK VAULT ──── single artifact store (manifest + viewer)
        │
        ├──► DOCS ── one document per Evidence Register entry (EV id), HTML + PDF
        │      ▲
        │      └── LEGAL WIKI ── Evidence Register, Master Timeline (WordPress; read-only for agents)
        │                 └──► RESEARCH ── database copy of the wiki (timeline, chronology)
        │
        ├──► PRIMARY RECORDS ──► Grammar House, FCG, Old Bill, Counting House,
        │                        Nomenclature, Directory, Independent Review, Land Changing Hands
        ├──► The Story, Map Room, Chessboard, farmbook, E-book Shelf, Terrain, Gift Shop
        │
  POST OFFICE (email archive) ──► Calendar ──► DISCLOSURE DARTBOARD
        │                                         │
        └──────────────► Public Authorities, Q&A Hall, Case Office, farmbook 2 ◄──┘

  PROJECT OFFICE reads every site's status  ·  CEDWYN ESTATE holds the tour order (site_chain.json)
  LIBRARY (this site) holds the standards and the manuals for all of them

Rules for moving information

  • A fact is edited where it is owned, then flows out; a site never corrects a copy of another site’s fact. Raise it with the owner instead.
  • Settled dates, names and statuses that appear on more than one site match the consistency ledger word for word.
  • Every evidence citation resolves to its EV document on Docs; every artifact link points to Wayback.
  • The Legal Wiki is edited by people with WordPress rights only; agents read it and propose.
  • New artifacts arrive through the evidence sweep with a Wayback manifest entry; no site uploads its own copy (single-source artifacts).
  • The tour order lives only in campus/site_chain.json (BucklerFamilyFarm); the static ‹ › block on the Legal Wiki is regenerated with campus/wiki_header.py after any change.

Machine copies: library.json (owns / reads per site) · each site’s /.well-known/mcp.json.
