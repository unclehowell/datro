# nomenclature.bucklerfamily.estate

Nomenclature: every name the records use for the same thing — Great House Farm (Tŷ Mawr), Llandough-juxta-Penarth: the farm,
Mary (Nancy) Williams, formerly Buckler, the parcels, the woodland, the green (VG41) and Church View Close, BP and Western Ground
Rents, the Land Registry titles, and the institutions whose own names changed.

- Landing page: one search box and an A–Z of things. Each thing has a page listing every wording, oldest first, with the record,
  its date and a link to the source page on the Legal Wiki (greathousefarmwiki.wordpress.com).
- `public/lexicon.json`: the data (built from work/nomenclature/lexicon.json). `SOURCE PENDING` = no record found yet.
- `public/term.js`: the reusable term modal (ⓘ more information on the Legal Wiki · translate icon = nomenclature page).
  Any bucklerfamily.estate site can include it with one line:
  `<script src="https://nomenclature.bucklerfamily.estate/term.js" defer></script>`
- Aliases nomlecture.bucklerfamily.estate and nolecture.bucklerfamily.estate forward here.
- Static site: Cloudflare Pages project bucklerfamily-nomenclature, branch `nomenclature`, output `public/`, no build step.
