# ebooks.bucklerfamily.estate

Catalogue of the Great House Farm / Tŷ Mawr e-books. Static site; Cloudflare Pages project `bucklerfamily-ebooks`
serves this branch (`ebooks` of unclehowell/datro), output directory `public/`, no build command.

- `public/index.html` and `public/books.json` are generated on the build box from the private catalogue
  (versions.json) by `build_site.py`; only public fields are published. No PDF is ever stored here.
- Theme: the shared Starlink-style theme (Barlow, SIL OFL) from fcg/projects. Language: the shared ghf-lang
  dropdown (bucklerfamily.estate/ghf-lang/) with this site's dictionary at `public/lang/ebooks.json`.
- Paid book: links to the shop at bucklerfamily.estate/ebook/ (no second checkout here). Other books: coming soon.
