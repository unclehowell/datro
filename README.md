# csscpsg.bucklerfamily.estate

v3.0.0 (21 Oct 2026): a plain-text legal chronology, earliest known to latest (public/index.html, rendered by work/csscpsg/build_plain.py from public/data/chronology.json). One line per instrument, order, registration, notice, statute, request or reply: date as in the source, citation, source. No headers, no wrapping. Lines not compliant with the site's six structural rules S1–S6 (public/data/model.json) are red; tapping one opens the rule breached and its evidence. The earlier v2.0.0 view (passages and arguments to reopen) is kept at /v2/.

Static site: Cloudflare Pages project bucklerfamily-csscpsg, branch `csscpsg`, output `public/`, no build step. csscpsgp.bucklerfamily.estate serves the same project and forwards to csscpsg.
