Manual · The Q&A Hall · Agent interface

How AI agents read The Q&A Hall: the WebMCP tools and the plain JSON endpoints behind them, with requests checked live on 24 Oct 2026.

Discovery

  • https://qa.bucklerfamily.estate/llms.txt — guide for language models (200)
  • https://qa.bucklerfamily.estate/.well-known/mcp.json — every tool as JSON, callable with a plain GET (200)
  • https://qa.bucklerfamily.estate/agent/tools.json — the tool list (200)
  • https://qa.bucklerfamily.estate/agent/webmcp.js — WebMCP: registers the same tools with navigator.modelContext in browsers that support it (loaded by the shared header, or injected on the home page) (200)

Tools

ToolEndpointWhat it returns
list_pagesGET /agent/pages.jsonList every page on this site with its title, path and one-line description.
searchGET /agent/searchSearch this site's pages (titles, headings and text). Returns the best matches with a snippet.
get_pageGET /agent/pageGet one page's title, description, headings and main text by its path (slug), e.g. / or /risk-register/.
search_qa_kbGET /agent/tool/search_qa_kbEvery question put to public bodies and the answer, status and exemption. Filter with q.
askGET /agent/tool/askAsk the Q&A knowledge base a question in plain words.
