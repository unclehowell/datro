Manual · Terrain · Cedwyn Estate in 3D · Agent interface

How AI agents read Terrain · Cedwyn Estate in 3D: the WebMCP tools and the plain JSON endpoints behind them, with requests checked live on 24 Oct 2026.

Discovery

  • https://terrain.bucklerfamily.estate/llms.txt — guide for language models (200)
  • https://terrain.bucklerfamily.estate/.well-known/mcp.json — every tool as JSON, callable with a plain GET (200)
  • https://terrain.bucklerfamily.estate/agent/tools.json — the tool list (200)
  • https://terrain.bucklerfamily.estate/agent/webmcp.js — WebMCP: registers the same tools with navigator.modelContext in browsers that support it (loaded by the shared header, or injected on the home page) (404)

Tools

ToolEndpointWhat it returns
get_sceneGET /agent/scene.jsonThe current 3D scene: every object with id, name, kind, position, colour and link, plus time of day and weather.
list_versionsGET /agent/versions.jsonSaved versions of the scene, newest first.
search_objectsGET /agent/search.jsonFind objects in the scene by name or kind.
get_roadmapGET /agent/roadmap.jsonThe disclosure roadmap: one trail per institution with its eleven escalation steps (request to court), each step's status and date.
get_trigger_sopGET /agent/sop.jsonThe trigger-event procedure as a branching graph of steps, gates, routes and outcomes.
list_dueGET /agent/due.jsonRoadmap steps falling due in the next N days (0 = today).

Gaps

  • /agent/search is not served here; the site’s own tools above replace the generic set.
  • No /agent/webmcp.js on this host; agents use the JSON endpoints.
