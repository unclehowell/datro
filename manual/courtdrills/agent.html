How AI agents read Court Drills.

Discovery

  • https://courtdrills.bucklerfamily.estate/llms.txt — guide for language models, every point listed
  • https://courtdrills.bucklerfamily.estate/data/register.json — the whole register as JSON

Examples

curl -4 -s "https://courtdrills.bucklerfamily.estate/data/register.json" | jq '.points[] | select(.k=="P") | {id, date, forum, t}'
curl -4 -s "https://courtdrills.bucklerfamily.estate/llms.txt"

Gaps

  • No /agent/* tools or WebMCP registration yet: the site is not in the shared agent layer's registry. Adding it (sites.json, build, deploy) gives list_pages, search, get_page and a get_points tool over data/register.json.
