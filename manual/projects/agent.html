Manual · The Project Office · Agent interface

How AI agents read The Project Office: the WebMCP tools and the plain JSON endpoints behind them, with requests checked live on 24 Oct 2026.

Discovery

  • https://projects.bucklerfamily.estate/llms.txt — guide for language models (200)
  • https://projects.bucklerfamily.estate/.well-known/mcp.json — every tool as JSON, callable with a plain GET (200)
  • https://projects.bucklerfamily.estate/agent/tools.json — the tool list (200)
  • https://projects.bucklerfamily.estate/agent/webmcp.js — WebMCP: registers the same tools with navigator.modelContext in browsers that support it (loaded by the shared header, or injected on the home page) (200)

Tools

ToolEndpointWhat it returns
list_pagesGET /agent/pages.jsonList every page on this site with its title, path and one-line description.
searchGET /agent/searchSearch this site's pages (titles, headings and text). Returns the best matches with a snippet.
get_pageGET /agent/pageGet one page's title, description, headings and main text by its path (slug), e.g. / or /risk-register/.
get_registersGET /agent/tool/get_registersRead the PRINCE2 registers live as JSON tables: issue, risk, quality, product, lessons, daily log, work packages. Give register to read one; omit it for all.
get_highlight_reportGET /agent/tool/get_highlight_reportRead the latest PRINCE2 highlight report (or one by id, e.g. hr-03) live: status, RAG, work packages, issues, risks and decisions.
get_pidGET /agent/tool/get_pidRead the Project Initiation Documentation (the project's front page) live: project, stage, next gate, status and sections.
get_asset_registerGET /agent/tool/get_asset_registerThe Cedwyn Estate asset register (JSON).
