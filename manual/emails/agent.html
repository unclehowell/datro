Manual · The Post Office · Calendar · Agent interface

How AI agents read The Post Office · Calendar: the WebMCP tools and the plain JSON endpoints behind them, with requests checked live on 24 Oct 2026.

Surfaces

emails.bucklerfamily.estate forwards to the calendar at https://email.bucklerfamily.estate/calendar/, so agents use the Post Office host: its search_threads tool and the files listed in the Post Office agent interface.

9 · Machine endpoints (as recorded in the SOP)

Every site also serves /llms.txt, /.well-known/mcp.json, /agent/pages.json, /agent/search?q= and /agent/page?slug=. Reference: API, WebMCP.

Gaps

  • No calendar tool: the correspondence calendar and its forecast have no JSON endpoint or WebMCP tool of their own.
