2 · Source of truth and data flow

This site owns: The 'now' album edition for 2005 onwards.

It reads: The Post Office and the Dartboard only.

Artifacts are linked from Wayback and open in the shared artifact viewer; no copy is kept on this site (single-source rule).

3 · Design system (frozen)

The current layout, navigation, colours, typography and the shared header are frozen. Any change to them is a class C change request approved by the executive. Pages start directly under the shared header; no repeated page titles.

7 · Deploy and verify

Branch: fb
Route to live: datro@fb (FB_EDITION=now → site2/; Pages bucklerfamily-fb2)

Then verify live at 390 px and 1280 px as in deploy and verify.

Shared layer

  • Header and tour bar: ghf-boot.js?v=2.1.4, the last element in <head>, loads basecamp.js (WALES | PATAGONIA | AI bar, the ‹ › tour bar, language menu EN/CY/ES, day/night). The order comes from campus/site_chain.json in unclehowell/BucklerFamilyFarm.
  • Tokens: ghf-tokens.css and the site’s own colour pair (see the brand guideline).
  • Artifacts: links open from Wayback in the shared viewer (wayback.bucklerfamily.estate/viewer/ghf-viewer.js); no site keeps its own copy (information flows).
  • Agent layer: the agent-ready Worker answers /llms.txt, /.well-known/mcp.json, /agent/* and /agent/webmcp.js on the site’s host (agent interface).
