Manual · The Council Chamber · Agent interface

How AI agents read The Council Chamber: the WebMCP tools and the plain JSON endpoints behind them, with requests checked live on 24 Oct 2026.

Surfaces

The council-meeting record is frozen and passed through the agent layer untouched, so /agent/* returns the page itself. Agents read the page HTML; the Project Office tools carry its outcome in the registers.

9 · Machine endpoints (as recorded in the SOP)

Every site also serves /llms.txt, /.well-known/mcp.json, /agent/pages.json, /agent/search?q= and /agent/page?slug=. Reference: API, WebMCP.

Gaps

  • Frozen record: no llms.txt section, no tools. Adding the host to the agent layer is a class C change once the record is closed for edits.

Estate-wide: API reference · WebMCP tools. Agents read; writes go through change control.
