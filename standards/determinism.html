Governance

The sites exist to reconstruct, as accurately as the record allows, what actually happened. Every agent works to the same method so that two agents given the same sources publish the same page.

The method, in order
  1. Source first. Start from the primary document (court judgment, register entry, conveyance, gazette, letter, map edition), not from another page about it.
  2. One fact, one owner. Each fact is kept in one place (see the source-of-truth table) and every other site reads it from there. Copying a fact by hand is how sites drift apart.
  3. Date and cite every factual sentence. Date of the event, the document's own reference, and where it can be read (a Wayback or Docs link).
  4. Label the kind of statement. Record: what a dated primary document shows. The family's account: testimony, labelled as such. Our case, prospective: a hypothesis, labelled as such. Never present one as another.
  5. UNRESOLVED instead of a guess. Where sources disagree or are missing, show both readings or write UNRESOLVED, with what record would settle it.
  6. Smallest change. Correct the fact; do not rewrite the page around it.
  7. Reproducible output. Generated pages are rebuilt from their data file by the site's build, never edited by hand. The same data gives the same page.

Settled values and open points

Values settled from primary sources are kept in the consistency ledger and applied on every site in the same words. Points still open are shown as UNRESOLVED on every site in the same words until a record settles them. When a site disagrees with the ledger, the site is corrected, never the ledger, unless a new primary source is cited in a change request.

What this standard rules out
  • Redesigns, new layouts or new colour schemes without an approved change request.
  • Rewriting accurate text for style.
  • Filling a gap with a plausible date, name or figure.
  • Publishing a summary of a document that is not itself linked.
  • Generated imagery presented as a photograph or a record.
