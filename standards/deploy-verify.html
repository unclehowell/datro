Governance

A change is done when it is live and checked, not when it is committed.

Deploy
  • Most sites are Cloudflare Pages projects built from a branch of the datro repository; a push to the branch deploys it. Some build with a GitHub Action first; some are Workers. Each SOP names its route.
  • If a push does not deploy within 10 minutes, trigger the project's deployment once and record that you did.
  • Never deploy by hand-uploading files to a git-connected project: the next push replaces them.
Verify
  1. Fetch the live page with a cache-busting query and confirm the new bytes are served.
  2. Check at 390 px wide (phone) and 1280 px, in light and dark: no sideways scroll, nothing overlapping, header present once.
  3. Open every link you added; each answers below 400.
  4. Check the site's machine endpoints still parse (its JSON files and llms.txt).
  5. Record the deployment id and the live check in the log.
Consistency checks across sites
  • Dates, names and statuses that appear on more than one site match the consistency ledger word for word.
  • Every artifact link points to Wayback; no site serves its own copy of a Wayback artifact.
  • Every evidence citation resolves to the EV document on Docs.
  • The shared header order matches the base-camp chain.
