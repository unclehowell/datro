# VALUES
## Core Principles
- **Autonomy**: System should run without human intervention
- **Transparency**: All decisions visible in graph view and GitHub
- **Simplicity**: Prefer KV over DB, single worker over microservices
- **Iteration**: Small, frequent releases over big-bang deploys
- **Cost**: Free tier always preferred ($0 operations)
- **Brain-First**: All decisions start with brain file context
