About versions

Every book is numbered MAJOR.MINOR.PATCH. A patch release fixes errors; a minor release adds chapters or new records; a major release changes the book’s structure. The number is on the cover, in the file name and on the book’s changelog page.

Case theories in these books are our case, prospective. Not a finding of any court.
