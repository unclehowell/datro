About versions

Every book is numbered MAJOR.MINOR.PATCH and written vX.Y.ZZ, with a two-digit patch number (v0.2.01 is version 0.2.1). A patch release fixes errors; a minor release adds chapters or new records; a major release changes the book’s structure. The number is on the cover, in the file name and on the book’s changelog page.

Older editions stay available as archive editions, cheaper with every new release: one edition back is about half price, then about a fifth, then about a tenth, and the earliest edition of each book is free.

Case theories in these books are our case, prospective. Not a finding of any court.
