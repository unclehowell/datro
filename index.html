cnei — DATRO Flywheel Engine

Cloudflare Workers-based autonomous release pipeline that rotates through 18+ branches, applying AI-driven improvements, best-practice audits, and evidence discovery. Every 10 minutes a cron triggers one branch cycle.

Architecture

Runtime
Cloudflare Workers (datro-flywheel) running on a */10 * * * * cron schedule. KV namespace FLYWHEEL_STATE for persistent state (rotation index, index cards, cooldowns, hypothesis trees). No database or external runtime dependencies.
Branch Rotation
Each cycle picks one branch via round-robin (regular_index). CNEI branch runs every 6 regular cycles (CNEI_RATIO = 6). Cooldown per branch is gear-based (RATE_BY_GEAR[gear-1], default gear 3 → ~233s per branch).
Release Pipeline (per branch)
  1. Check branch exists via GitHub API
  2. Compute next version from latest tag (branch-vX.X.X.XX)
  3. Load index card from KV (branch state, cycle count, failures)
  4. Run git diff analysis against last release
  5. Fetch contextual research (Semantic Scholar)
  6. Scan MCP tools (EAA accessibility, AccessScore)
  7. Apply wing-file visual steering blocks
  8. Run agentic AI loop (brainstorm + write_file + read_file tools)
  9. If agent made changes → tag & release; else fallback to best-practice engine
  10. If no improvements → audit-only release
  11. Sync index card to Monday.com

Quota Management

KV Operations Budget

Cloudflare Workers free-plan KV limits: 100K reads / 1K writes per day.

Optimisations applied to stay within budget:

  • Concurrency lock uses TTL auto-expiry (no explicit delete)
  • Index cards only updated on state changes, not every cycle
  • Branch wallet cached in KV with 24h TTL
  • MCP scan results cached (48h refresh cycle)
  • Circuit breaker: if cumulative KV writes approach limit, gear auto-adjusts

Estimated daily usage: ~450 reads / ~350 writes (well within free tier).

Evidence Discovery (Wayback)

Great House Farm — Llandough (nr. Penarth)

The wayback branch includes a GitHub Action that runs on every push, using the flywheel's AI proxy to discover new unique evidence about Great House Farm. Each wayback re-release adds at least 1 new entry to the library at wayback.datro.xyz.
