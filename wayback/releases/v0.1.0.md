# Wayback Archive v0.1.0
Release date: 2026-10-16

## Summary

This release repairs archive media delivery, removes duplicate Text and Email tabs, and establishes a semantic-version release process.

## Changed

- Replaced the separate **Text** and **Email** navigation entries with one **Text / Email** tab. Email correspondence remains in the text catalogue, with the existing `#email` filter retained.
- Kept the old `?cat=email` deep link working by opening Text / Email with the email filter applied.
- Changed the release version to stable SemVer `0.1.0` and added a GitHub Actions workflow that validates the version and matching notes before publishing `wayback-v0.1.0`.

## Fixed

- Added a Cloudflare Pages Function that serves catalogue media from the existing `wayback-media` R2 binding for the `images/`, `pdf/`, `text/`, and `video/` paths.
- Media responses preserve the stored content type and stream the R2 object body, so the gallery can replace “Loading…” placeholders with the actual media.
- HTML pages and `_treeview.json` manifests remain static Pages assets. The whole R2 bucket is not made publicly accessible through an R2 development domain.

## Deployment

- Production branch remains `wayback`; Cloudflare Pages build root remains `wayback`.
- Release creation is triggered by the version file changing and requires a valid `X.Y.Z` version plus a matching `wayback/releases/vX.Y.Z.md` file.
