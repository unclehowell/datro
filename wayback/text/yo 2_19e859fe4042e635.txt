Project: Make bpvsbuckler.datro.xyz Fully Machine-Readable, Searchable, and
Evidence-Centric

Objective:

Transform the website into a structured historical evidence repository that
can be easily understood, indexed, searched, cited, and analysed by:

   - AI systems (ChatGPT, Claude, Gemini, Perplexity, etc.)
   - Search engines
   - Journalists
   - Historians
   - Lawyers
   - Researchers
   - Members of the public

Requirements:

   1. Create a Case Summary Page

Create a single page called:

/summary

This page must contain:

   - Overview of the Great House Farm (Ty Mawr) dispute
   - Key parties
   - Key dates
   - Principal documentary evidence
   - Main unresolved questions
   - Links to all major evidence collections

Keep factual and concise.

   2. Create a Master Timeline

Create:

/timeline

Chronological structure:

Date Event Document Reference Source Link

Every event should link directly to supporting evidence.

Timeline must be rendered as plain HTML and not require JavaScript.

   3. Create an Evidence Catalogue

Create:

/evidence

Each document should have:

   - Unique evidence ID
   - Title
   - Date
   - Description
   - Download link
   - Full transcription
   - OCR text
   - Source information

Example:

Evidence 001 1974 Newspaper Article Date: Description: Full Text: Download:

   4. OCR and Transcribe Everything

Every image, scan, PDF, newspaper clipping, court document, letter and
record should have:

   - Original file
   - OCR text
   - Human-corrected transcription where possible

The transcription must appear directly on the page beneath the image.

No important evidence should exist only as an image.

   5. Create Claim-to-Evidence Mapping

Create:

/issues

For each issue:

Issue: Supporting Evidence: Evidence IDs: Counter-Evidence: Open Questions:

Examples:

Ownership Claim

Supporting Documents: Evidence 001 Evidence 023 Evidence 045

Open Questions: ...

   6. Create Contradictions Index

Create:

/contradictions

Structure:

Contradiction Number Document A Document B Explanation

Each contradiction should cite exact document locations and quotations.

   7. Create Open Questions Repository

Create:

/questions

List unresolved questions.

For each question include:

Question Relevant Documents Known Facts Unknown Facts

Do not provide conclusions.

   8. Provide Direct Quotations

Important quotations should appear as selectable HTML text.

Avoid requiring users to open PDFs to locate key statements.

   9. Create a Research Dossier

Generate:

/dossier

Single downloadable formats:

   - HTML
   - PDF
   - Markdown

Containing:

   - Summary
   - Timeline
   - Evidence Index
   - Contradictions
   - Open Questions


   10. Create AI-Friendly Site Architecture

Requirements:

   - Static HTML pages
   - Semantic headings (H1, H2, H3)
   - Internal linking
   - Human-readable URLs
   - Sitemap.xml
   - robots.txt
   - Structured metadata

Avoid placing core evidence behind:

   - JavaScript rendering
   - Popups
   - Image-only galleries
   - Interactive viewers


   11. Create a Sources API

Provide:

/api/evidence.json /api/timeline.json /api/issues.json

Machine-readable structured data.

   12. Distinguish Evidence from Interpretation

For every page maintain separation between:

A. Documentary Facts

and

B. Interpretations, hypotheses, or unresolved issues.

Never merge the two.

   13. Citation System

Every claim should link to:

   - Evidence ID
   - Original document
   - Exact page reference where possible


   14. Create a "Start Here" Page

A visitor should be able to understand:

   - What happened
   - Why it matters
   - What evidence exists
   - What questions remain

Within 10–15 minutes.

Success Criteria:

An independent researcher, journalist, lawyer, historian, search engine
crawler, or AI model should be able to reconstruct the chronology, review
the evidence, verify citations, and understand the unresolved issues
without requiring prior knowledge of the case.
