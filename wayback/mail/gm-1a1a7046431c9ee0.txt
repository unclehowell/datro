Further to your Subject Access Request please see attached PDF portfolio for our response.

You will need to save the portfolio to your PC/Phone before you attempt to open it. Once downloaded you should be able to click on the file to view/open.
NB: Most modern computers (Windows and Macs) have built-in PDF readers that are basic. Phones and tablets usually have PDF readers pre-installed however the following points may be of assistance:

  *   PC/Laptop: You should be able to open the document with which ever programme you use to view PDF files, such as Edge or Chrome. Save the file to your PC, double click the PDF file to open.
  *   Android Phone/Tablet: Download/save the PDF file, open the file from the download folder, tap the PDF file to open it.
  *   iPhone/iPad: You should be able to view the PDF via the inbuilt viewer in the mail app, click on the PDF file to open.
  *   Mac: The inbuilt preview programme should allow you to view the document without any additional software. Save the PDF to your Mac, click the file to open.

Please note that the attached PDF portfolio has been password protected. The password will be sent to you in a separate email.
